# **JavaScriptmas Day 1 – Grandpa’s Gift List**

### A small JavaScript mini‑project that lets the user add items to a Christmas gift list.  
### Each item appears with a 🎁 icon and a handwritten-style font, creating a simple, festive interface.  
<br>

## 🧩 **About the challenge**  
### This project was created as part of the Scrimba JavaScriptmas challenges, which I completed to practice JavaScript and DOM manipulation.  
### I’m using these challenges to build small, independent projects outside of FCC and CYF, to show variety in my learning path.  
<br>

## ✨ **Features**  
### Add items to the list  
### Gift icon 🎁 automatically added  
### Styled input, button, and label  
### Custom fonts (Poppins + Caveat)  
### Clean, simple UI with a light festive theme  
<br>

## 🧠 **How it works**  
### The user types an item into the input field  
### The script listens for a click on the “Add Item” button  
### A new `<li>` element is created and added to the list  
### The 🎁 icon is applied using CSS list-style  
### The item text is displayed using the Caveat font  
<br>

## 📁 **Files**  
### index.html – main page  
### index.css – styling for layout, fonts, button states, and list  
### index.js – JavaScript logic (loaded as a module)  
<br>

## 🚀 **What I learned**  
### How to manipulate the DOM with getElementById and addEventListener  
### How to create and append new elements dynamically  
### How to style form elements and button states (hover, focus, active)  
### How to use custom fonts (Poppins + Caveat)  
### How to build a small interactive UI without a tutorial  
<br>
